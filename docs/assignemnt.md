The Task
Build a remote browser control system — think of it like a mini TeamViewer, but for a browser.
What it should do
You open a web UI in your browser
You hit a button — "Start Browser."
A Docker container spins up locally and starts Chromium in headless mode
The browser screen streams back to your web UI in real time
You can click, scroll, and type from the web UI — and it happens inside that headless browser
No deployment needed. Everything runs locally on your machine.
